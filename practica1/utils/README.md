 # Carpeta utils
En esta carpeta contiene funciones que sirven para generar el conjunto de datos.
La funcion files, sirve para filtrar los nombres de las imagenes, tanto aquellas que son de patch, como aquellas que no son patch.

EN el archivo dataset, se generan los conjuntos de datos

En los archivos con los nombres de los algoritmos y seguidos por el termino _ generator _, contienen las funciones necesarias para aplastar los valores,(si se requiere) y la flattenizacion de las imagenes, asi como tambien asociacion correcta del valor de label
