# La carpeta lib
En la carpeta lib se encuentra 4 archivos importantes para la practica

## samples

El archivop samples,contiene una clase denominada samples que es la que permite realizar los recortes a las imagenes

## SDH

Es el archivo en donde contiene la clase SDH que permite hacer el calculo de la suma y diferencia de histogramas

## GLCM

Contiene el archivo con la clase homonima que permite el calculo de las matrices de co-ocurrencia.

## LBP

Contiene el archivo con la clase homonima para el calulo del LBP

Cada una de las clases almacena las imagenes calculadas, para despues ser calculadas sus metricas.

En esta carpeta no contiene la generacion de los datasets, solamente los calculos y la generacion de sub samplings
