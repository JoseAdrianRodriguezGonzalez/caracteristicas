# src

En esta carpeta contienen los archivos que ejecutan la union de todo el codigo. 
## test.py
ESte archivo solamente contiene codigo de prueba que ayudo a las pruebas del desarrollo

## main.py

Es el archivo que contiene todo el proceso

Para esto, el primero bloque de abstracion fuerons los samples que se generan y almacenan. El segundo es la generacion de los algoritmos, el tercero es la falttenizacion y compactacion de los datos, y finalmente la generacion de conjuntos de datos. EN esta funcion se llama a los generadores de los conjuntos de datos que realizan el pipeline previamente descrito
