\section{Introducción}
En este trabajo se realizó la recolección de los datos, se tomaron capturas a 6 objetos
\begin{itemize}
    \item Cono
    \item Taza
    \item Carro
    \item Botella de cloro
    \item SIlla
    \item Figura de juguete
\end{itemize}
Para esta tarea, se necesito una cámara Intel realsense 430. Por medio de esta cámara capturaba las nubes de puntos en profundidad. Durante la toma de capturas se realizaron procesos de filtrado para poderle calcular características independientes entre sí. Al calcular las características se subsamplea dado a la cantidad de números de puntos y finalmente se entrena un modelo de árbol de decisión. Todos estos procesos se realizaron con técnicas vistas hasta el momento
\section{Metodología}
Se creo un entorno de conda con los siguientes comandos
\begin{verbatim}
# !/bin/bash
conda create --name ml python=3.9
conda activate ml
conda install pip
pip install open3d opencv-python pyrealsense2 datetime
\end{verbatim}
Esto es necesario debido a que el script desarrollado en python para tomar capturas se realizó con paquetes que tienen disponibilidad en la versión de python 3.9, si se realiza con una versión más reciente, existen paquetes que terminan en conflictos. El script únicamente toma las capturas con el botón \textit{q} y se termina de ejecutar el programa con el comando \textit{ESC}. Las imágenes se almacenan dentro de la carpeta llamada \textit{captured_data}, Dentro de ella se crean carpetas con la fecha y hora de creación de las carpetas.
